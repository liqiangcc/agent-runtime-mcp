# agent-runtime-mcp v0.2.2

`v0.2.2` packages the accepted phase-correlation diagnostics from Issue #50
without changing the generic terminal Channel MCP contract.

## Phase diagnostics

Diagnostics are disabled by default. To opt in for a controlled diagnostic
run, set the exact environment variable:

```sh
AGENT_RUNTIME_MCP_PHASE_DIAGNOSTICS=1
```

When enabled, the server emits bounded, field-whitelisted JSONL records to
stderr only; stdout remains reserved for MCP framing. All seven public Tools
retain their existing names, schemas, results and errors. Each Tool records
`method_start` and `method_end`; `read_channel` additionally records
`backend_start` and `backend_end` around the actual read action.

`backend_end` means that `readChannel(...)` settled, before product result or
error shaping and JSON serialization. `method_end` means Tool callback/handler
completion only. Neither phase proves SDK response encoding, stdio write or
drain, bridge forwarding, connector posting or remote receipt.

Records contain only a fresh server-local correlation id, a deterministic
non-raw request-id fingerprint, phase/method timing, outcome, allowlisted error
codes and bounded read shape. Terminal or write content, raw request IDs,
cursors/tokens, full arguments/results/errors, credentials, URLs and
environment values are excluded.

## Scope and known limitation

The seven-tool surface, observation/cursor semantics, bounded reads/writes,
explicit controls, cancellation and endpoint lifecycle remain unchanged.
These diagnostics provide localization evidence only. The external latency
class documented in Issue #48 (roughly 45–111 seconds for external calls) is
not claimed fixed by v0.2.2; a controlled diagnostic deployment and retest is
a separate operator action.

## Download and installation

Download the archive and independent checksum from the v0.2.2 GitHub Release:

```sh
curl -fLO https://github.com/liqiangcc/agent-runtime-mcp/releases/download/v0.2.2/agent-runtime-mcp-v0.2.2.tar.gz
curl -fLO https://github.com/liqiangcc/agent-runtime-mcp/releases/download/v0.2.2/agent-runtime-mcp-v0.2.2.tar.gz.sha256
sha256sum -c agent-runtime-mcp-v0.2.2.tar.gz.sha256
tar -xzf agent-runtime-mcp-v0.2.2.tar.gz
cd agent-runtime-mcp-v0.2.2
npm ci --omit=dev
```

Use the extracted directory as an operator-managed runtime path. Deployment,
service cutover and rollback are independent operator actions; diagnostics
must be explicitly enabled only for an approved controlled run.
